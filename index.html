HOW I WORK

My Product Workflow

A simple 5-stage process from initial problem discovery to shipped functional interface.

01

Discover

Understand users, business goals and constraints before proposing design directions.

02

Define

Clarify the core problem, user friction points, and prioritize key feature opportunities.

03

Design

Create user flows, wireframes, high-fidelity UI systems and interactive prototypes in Figma.

04

Build

Use AI-assisted development to turn the design system and UI specs into functional interfaces.

05

Iterate

Test the working build, refine interactions, gather user insights, and continuously improve.
