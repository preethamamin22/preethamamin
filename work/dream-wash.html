PROJECT 02 UX/UI · Mobile Experience

Dream Wash

A simpler digital experience for laundry services.

Role Product Designer
Focus UX/UI · Mobile Design · User Journey · Prototype
Tools Figma · Mobile Components · Journey Maps
Timeline 2 Weeks Concept & Design
01 / THE PROBLEM

Friction in On-Demand Laundry

Traditional laundry services require manual call schedules, uncertain pickup windows, and zero visibility into clothing status (washing, folding, or out for delivery). Users need a reliable, effortless 3-tap booking flow with real-time status notifications.

02 / USER JOURNEY

04 Doorstep Delivery Clean & folded
03 / WIREFRAMES & EXPLORATION

Iterating for Maximum Clarity

Bag Capacity Visualizer

Replaced text-heavy weight descriptions with simple bag icons specifying estimated clothing counts (e.g., Standard = ~15 lbs / 20 items).

Progress Timeline

Designed a vertical milestone stepper so customers immediately know if clothes are in washing, drying, or delivery transit.

06 / LEARNINGS

Key Design Insights

1. Reducing Decision Fatigue: Pre-packaged bag choices outperform itemized garment counts for daily wash-and-fold services.

2. Visual Status Confidence: Live progress bars significantly reduce customer support calls regarding order estimated times.
